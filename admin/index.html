Étape 1 / 2 — l’invitation est à usage unique.

Ajoutez ce compte dans votre application d’authentification (Google Authenticator, Microsoft Authenticator, Aegis, 1Password…) avec la clé ci-dessous, puis saisissez le code affiché.
